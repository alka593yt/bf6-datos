Panel de armas BF6

Para editar los datos necesitas tu clave de GitHub. Se guarda solo en este navegador.

¿Cómo creo la clave?
  1. Abre github.com/settings/personal-access-tokens/new.
  2. Nombre: "Panel BF6". Caducidad: la que prefieras (por ejemplo, 1 año).
  3. Repository access: Only select repositories → bf6-datos.
  4. Permissions → Repository permissions → Contents: Read and write.
  5. Pulsa Generate token, cópialo y pégalo aquí.
